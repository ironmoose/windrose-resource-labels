# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project aims to follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html) once it reaches its first release.

## [Unreleased]

Work in progress. There is no released version yet.

### Added

- Initial project setup: repository structure, documentation, and contribution guidelines.
- Documentation for players and contributors: README, installation guide, a plain-language "how it works" explainer, research notes on the community demand, and a contributing guide with the full art-style spec.
- Issue templates for bug reports and feature (resource) requests.
- `art/` folder set up to hold original source icon art.

### In development

- **Iron resource label**, the first per-resource plaque (a stack of iron bars in the game's chalky-white plaque style, distinct from the built-in "Ore" pickaxe plaque).
- The packaging and registration pipeline (building the mod into a drop-in UE5 IoStore pak file). Details are still being finalized.
